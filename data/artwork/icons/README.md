# Vector icons

SVG redraws of all wxFormBuilder bitmap icons plus the sources of the platform application and
document icons. The SVGs are generated by the Node.js scripts in `tools`; edit the scripts, not the
SVG files, and regenerate.

Currently the application still loads its bitmap icons. The SVGs are prepared to replace them later
(e.g. via `wxBitmapBundle::FromSVGFile`). The platform application and document icons in
`data/platform` are built from these sources by `tools/build_platform.js`.

## Layout

| Path | Content |
|---|---|
| `resources/icons/` | Application icons, mirroring `resources/icons` (same names, `.svg`) |
| `plugins/<plugin>/icons/` | Widget palette icons, mirroring `plugins/<plugin>/icons` |
| `sdk/plugin_interface/default.svg` | Fallback icon, mirroring `sdk/plugin_interface/default.xpm` |
| `platform/macos/icon.svg`, `docicon.svg` | macOS app icon (1024 grid, rounded-square plate) and `.fbp` document icon |
| `platform/linux/share/icons/hicolor/scalable/` | Scalable Linux app and mimetype icons (copied to `data/platform`) |
| `platform/sources/` | Pixel-hinted sources for raster sizes up to 32 px (`icon*`, `macicon*`, `docicon*`) |
| `tools/` | Generators, platform build and verification |
| `STYLE.md` | Drawing rules for all icons |

## Tools

Requires Node.js (no packages). Run from the repository root:

```sh
node data/artwork/icons/tools/build.js              # regenerate all SVGs and verify them
node data/artwork/icons/tools/build.js --platform   # additionally rebuild data/platform (Windows only)
node data/artwork/icons/tools/verify.js             # only verify
```

| Script | Generates |
|---|---|
| `gen_resources.js` | `resources/icons` (uses `resources22.js` for the 22 px icons), logos, `platform/` sources |
| `gen_additional_a.js`, `gen_additional_b.js` | `plugins/additional/icons` (split alphabetically at `propgridpage`) |
| `gen_common.js` | `plugins/common/icons` |
| `gen_containers_forms_layout_sdk.js` | `plugins/{containers,forms,layout}/icons`, `sdk/plugin_interface` |
| `build_platform.js` | `data/platform/{macos,windows,linux}` icons and the installer icon from the SVG sources |
| `verify.js` | Checks the set against the bitmaps: coverage, viewBox, stroke widths, ids, references |

`build_platform.js` renders with headless Microsoft Edge and crops with System.Drawing, so it needs
Windows. Its output is deterministic. Developer helpers in `tools/dev`: `dump.ps1` prints a bitmap
as character grid with palette, `preview.js` renders bitmap and SVG side by side for comparison.

## Platform icons

Files written by `tools/build_platform.js`:

| Platform | Files in `data/platform` | Sizes |
|---|---|---|
| Windows | `wxFormBuilder.ico` (application icon, also copied to the installer support files), `docicon.ico` (`.fbp` document icon) | 16, 20, 24, 32, 40, 48, 64, 256 |
| macOS | `icon.icns`, `docicon.icns`; `Info.plist.in` declares `org.wxformbuilder.fbp` | 16 … 1024 |
| Linux | hicolor `apps` and `mimetypes` icons | 16, 22, 24, 32, 48, 64, 128, 256, 512, scalable |

Small sizes use pixel-hinted sources: app 16/32 → `logo16x16`/`logo32x32`, app 20/22/24 →
`platform/sources/icon*.svg`, macOS app 16/32 → `macicon*.svg`, document 16…32 → `docicon*.svg`.

## Design decisions

- Pixel icons follow their bitmap's grid with 1 px contours on .5 coordinates (see `STYLE.md`).
- Logo squares are flat: a subtle two-stop gradient per colour, no gloss highlight (fits the
  Windows 11 and current macOS icon styles).
- Logo lettering "wxFB": angular letters without chamfers, slanted w with the middle apex at
  x-height and counters open down to their tips (like the x), F with a wide top bar, B with two
  equal bowls and rounded right corners; flat light blue fill with a dark outline. Lettering is
  paths, not a font, so every renderer shows it identically.
- `logo32x32` has no outline around the lettering: at 8 px cap height an outline closes the
  counters and letter gaps.
- macOS icons use Apple's 1024 grid (plate 824 px at 100,100, radius 185.4, soft drop shadow);
  Windows and Linux use the free-standing logo without plate.
